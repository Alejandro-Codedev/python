| Comando                   | Qué hace                          |
| ------------------------- | --------------------------------- |
| `git init`                | Inicia Git en tu proyecto         |
| `git status`              | Mira qué cambios tienes           |
| `git add .`               | Prepara todos los cambios         |
| `git commit -m "mensaje"` | Guarda una versión de tu proyecto |
| `git push`                | Sube los cambios a GitHub         |
| `git pull`                | Descarga cambios desde GitHub     |
